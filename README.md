# 🎯 Number Guessing Game (Java Swing)

A simple GUI-based Number Guessing Game built using Java Swing.

The system generates a random number between 1–100, and the user attempts to guess it. The program provides feedback whether the guess is too high, too low, or correct, while tracking the best score and total attempts.

## 🚀 Features

- 🎲 Random number generation
- 📊 Best score tracking
- 🔁 Play Again functionality
- ❌ Give Up option
- 🖥️ Java Swing GUI interface

---

## 🛠️ Technologies Used

- Java (JDK 17+)
- Swing (JFrame, JButton, JLabel, JTextField)
- AWT Event Handling
